## The entry

> My phone hits 20% by noon, then survives four hours on 1% — it's not a dying battery, it's gaslighting me.

## How it works

`main.ts` writes that single line, deterministically, to `/output/entry.txt`. Run it with Node 22.18+:

```sh
node main.ts
```

The output is byte-identical on every run: one line, 106 characters, no trailing newline.
